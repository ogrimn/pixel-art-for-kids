개인정보처리방침

픽셀아트 (https://pixelart.oneulgm.com)

1. 수집하는 정보

  • 운영자 서버에는 이름이나 그림을 저장하지 않아요.
  • 광고, 사용 분석 도구를 쓰지 않아요.

2. 저장되는 곳

  • 이름과 그림은 사용 중인 기기의 브라우저에 저장돼요.
  • 그림 파일 이름에는 입력한 이름이 들어가요(예: 철수_1105).
  • 밑그림 사진은 기기 안에서만 쓰이고 어디에도 보내지 않아요.

3. 구글 로그인 (선택)

  • 로그인하면 '드라이브에 저장'한 그림이 내 구글 드라이브 '픽셀아트' 폴더에 저장돼요.
  • 이 앱이 만든 그림 파일만 볼 수 있고, 드라이브의 다른 파일은 볼 수 없어요.
  • 로그인한 계정의 이름, 이메일, 사진은 화면에 보여 주는 데만 써요.
  • 구글에서 받은 정보는 그림 저장과 불러오기에만 쓰며, Google API 서비스 사용자 데이터 정책을 따라요.

4. 제3자 제공

  • 개인정보를 다른 사람이나 회사에 주지 않아요.
  • 사이트는 Vercel(미국)에서 운영돼 접속 기록(IP 주소 등)이 남을 수 있어요.

5. 만 14세 미만 이용

  • 만 14세 미만 학생이 구글 계정으로 로그인하는 경우, 보호자나 교사의 지도 아래 사용해 주세요.

6. 지우는 방법

  • 이 기기: '나의 스케치북'에서 지우거나 브라우저 데이터를 지워요.
  • 드라이브: 앱에서 지우면 휴지통으로 가고, 30일 뒤 자동으로 지워져요.
  • 권한 해제: 구글 계정 → 보안 → 타사 앱 및 서비스에서 픽셀아트를 삭제해요.
